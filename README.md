PDB Interface Analyzer

Wtyczka do PyMOL służąca do analizy interfejsu białko–białko na podstawie struktur PDB/CIF.
Napisana jako projekt do pracy licencjackiej.
Program automatycznie wykrywa i wizualizuje oddziaływania między dwoma wskazanymi łańcuchami (chains) w strukturze białkowej, licząc m.in. wiązania wodorowe, mostki solne, kontakty hydrofobowe oraz powierzchnię dostępną dla rozpuszczalnika (SASA/BSA).

Instalacja:

Otwórz PyMOL.

Przejdź do Plugin → Plugin Manager → Install New Plugin.

Wskaż plik licencjat.py

Po instalacji zrestartuj PyMOL.

Wtyczka pojawi się w menu Plugin → Analizator Interfejsu PDB.
